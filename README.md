# COGCRASHER
Cogcrasher is a Minecraft mod built around strange mechanical creatures, unusual blocks, and experimental gameplay mechanics. The mod is currently in active development, so many systems are unfinished and subject to change.
## Current Features
### Entities
- Blackstone Golem: A large hostile entity that targets players and other golem types. it rolls at it's target with its large body, and can only be damaged with dexterity, skill and a pickaxe. Takes no knockback and cannot be hurt while not stunned, so tread lightly whilst facing this formiddable foe. Drops some of the blocks it's composed of.
### Items
- Creaking Candy: A short food source, normally unreliable. Saturates 1 hunger point.
